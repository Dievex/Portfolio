# Expo en React

Expo es una plataforma que simplifica el desarrollo de aplicaciones móviles en React Native. Con Expo, puedes construir, compilar y desplegar aplicaciones de forma rápida, usando un conjunto de herramientas que facilitan el acceso a funcionalidades avanzadas sin necesidad de configuraciones complejas.

## Instalación

Para comenzar con Expo, asegúrate de tener **Node.js** instalado y ejecuta el siguiente comando para instalar Expo CLI globalmente:

```bash
npm install -g expo-cli
```
## Crear un Proyecto
```bash
npx create-expo-app nombre-del-proyecto
```
## Iniciar el Servidor de Desarrollo
```bash
npx expo start
```
## Ejecutar en un Emulador o Dispositivo
```bash
npx expo start --ios
npx expo start --android
npx expo start --web
```
## Dejar el proyecto en blanco
```bash
npm run reset-project
```
